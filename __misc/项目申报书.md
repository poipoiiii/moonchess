## 项目简介

moonchess 是一个用 MoonBit 从零实现的国际象棋库与 AI 引擎，面向需要在 MoonBit 中构建棋类
程序、对局工具、教学演示或 AI 应用的开发者，提供走法生成、合法性校验、局面表示与转换、
记谱以及一个可直接使用的 α-β 搜索引擎。项目以 0x88 棋盘表示和攻击检测为基础，接口风格对齐
成熟的 JavaScript 库 chess.js，便于其他语言生态的开发者快速迁移，同时补充了 chess.js 本身
不具备的 AI 搜索能力。

## 核心功能范围

- **棋盘与类型系统**：基于 0x88 的棋盘表示、`Color`/`PieceType`/`Piece`/`Move` 类型，完整
  的坐标（file/rank ↔ 代数记法）转换工具。
- **走法生成与合法性**：兵（升变、吃过路兵、双步）、马、象、车、后、王全部走法，王车易位
  （含路径被攻击时禁止）；通过“走后己方王是否被将军”过滤得到合法走法。
- **FEN 读写**：解析与生成标准 FEN，覆盖走子方、双方易位权、吃过路兵目标格、半回合计数、
  回合数。
- **SAN 记谱**：生成与解析标准代数记法，包含消歧、吃子、升变、易位以及 `+`/`#` 标记；
  支持以 SAN 字符串走子。
- **对局状态**：`is_check` / `is_checkmate` / `is_stalemate` / `is_draw` /
  `is_threefold_repetition` / `is_insufficient_material` / `is_game_over`；支持 `undo` 撤回。
- **AI 引擎**：子力价值 + 棋子位置表评估、negamax + α-β 剪枝、静止搜索、MVV-LVA 走法排序，
  提供 `best_move(depth)` 与带评分的 `best_move_scored(depth)`。
- **置换表搜索**：64 位 Zobrist 哈希 + 2^16 项置换表与迭代加深（`Searcher`）。
- **开局库**：内置常见开局线路，按 SAN 历史匹配续着。
- **PGN 读写**：导出标签对与走子文本；导入时忽略注释、变例、NAG 与内联回合号。
- **棋盘渲染**：Unicode / ASCII 棋盘输出。
- **perft 自检与测试**：内置 perft 节点计数，测试用标准局面（初始局面、Kiwipete、Position 3–6）
  校验走法生成的正确性。
- **浏览器演示**：`web/` 以 MoonBit 驱动 DOM（`extern "js"`），在浏览器中渲染棋盘、点击走子
  并调用引擎对战，可编译为 JS 运行。
- **CLI 示例**：`board` / `perft` / `divide` / `best` / `think` / `timed` / `selfplay` /
  `book` / `validate` / `fen` 子命令，以及 `examples/demo` 可运行示例。

## 现有基础

- 完成 `types` / `square` / `board` / `game` / `movegen` / `engine` / `search` / `book` /
  `pgn` / `display` 十个核心模块，以及命令行前端与可运行示例，已按 MoonBit 包结构组织并配置
  CI（`moon check` / `moon test` / `moon fmt` / `moon info`）。
- 走法生成已通过公开标准 perft 验证：初始局面深度 1–4 为 20 / 400 / 8902 / 197281，Kiwipete
  深度 1–3 为 48 / 2039 / 97862，Position 3–6 亦全部对齐。
- 已实现 α-β 引擎、Zobrist 哈希 + 置换表 + 迭代加深、开局库、PGN 读写与棋盘渲染，并提供覆盖
  FEN、perft、SAN、PGN、易位、吃过路兵、升变、撤回、将杀/逼和/和棋判定、哈希与引擎的测试。
- 提供浏览器演示（`web/`）与可运行命令行，可用于实际对局与展示。

## 预期目标与技术路线

以 MoonBit 作为唯一主实现语言，保持核心库无平台依赖，原生 / Wasm / JS 后端均可编译。技术
路线：先用 0x88 表示保证走法生成正确性（以 perft 为准），再在其上叠加评估与搜索；接口风格
对齐 chess.js 以降低使用门槛，功能上以“AI 引擎 + 可复用库”形成差异化价值。目标是把项目做成
边界清晰、可测试、可长期维护的 MoonBit 棋类基础库。
